
# Password Generator

## Project Description
Password Generator is a Python application that generates
random and customizable passwords based on user requirements.

## Features
- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special symbols
- Generate multiple passwords
- Password generation using secure randomness
- Input validation
- Generate passwords repeatedly

## Technologies Used
- Python 3
- Random Module
- String Module

## Project Structure

Password_Generator/
│
├── main.py
├── README.md
└── .gitignore

## Installation

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.

## Execution

Run the following command:

python main.py
